# Local Stock Recommendation Studio

A simple local website that generates a **buy / hold / sell** recommendation using weighted:

- Market trend signals
- Technical indicators
- Financial health metrics

## Run locally

From this folder, run:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Notes

- This project is intentionally lightweight and runs fully in the browser.
- Recommendation output is educational and should not be treated as investment advice.
